# 顺序预加载小助手

适用于在 Chrome 中顺序浏览本地资料库的原帖链接。需要用户确认安装后才启用，目前网站在没有小助手时保留普通浮窗打开方式。

## 使用

1. 在 Chrome 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选中本文件夹。
2. 从 `http://127.0.0.1:8799/` 或 `http://localhost:8799/` 打开资料库，刷新网页。页面会显示“已连接”。不要从文件地址直接打开。
3. 点击原帖后，小助手创建一个浏览浮窗，每隔 7 秒静音准备后面一条，最多准备后 5 条。回到资料页用上一条、下一条或上下键切换，直接激活已打开的页面。
4. 页面上可关闭“顺序预加载后5条”。关闭后停止后续准备；已打开的窗口可直接关闭。

## 范围

- 使用安装小助手的 Chrome 账号登录态，不复制登录信息，不更改账号。
- 仅接受本机 8799 端口资料页的请求，仅打开支持的平台帖子地址；不会打开列表外的搜索。
- 只保存本次浏览窗口和标签编号到浏览器会话存储，没有服务器、没有分析上报。申请的权限仅为会话存储。
- 最多保留当前页、上一页和后五页；超出范围会关闭由小助手创建的标签，不关闭用户其他标签。
- 原帖“页面已准备”不保证平台视频已全部缓冲，后台播放、节能和平台限制可能影响速度。遇到登录、验证码或访问异常，关闭预加载并由用户处理，不绕过限制。
- 不新增永久视频文件，不执行媒体下载或清理。浏览器正常缓存和后台页面会占一定内存。

网站内已有离线视频可直接预加载后 5 条，不需安装小助手。切换时复用已缓冲播放器，关闭弹窗或开关后释放预加载内容。

## 验证

本地视频已在实际 Chrome 验证五条缓冲以及下一条正常播放。小助手的来源检查、五条上限、七秒间隔、静音、切换复用、停止取消已通过模拟检查；安装和平台真实效果需要用户确认后验证。

运行检查：`node tests/test_preloader.cjs` 和 `node tests/test_ui.cjs`（从项目根目录运行）。
