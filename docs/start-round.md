# 启动一轮搜索与同步

## 默认触发

用户说“启动”“开始一轮”“更新选题中台”时，默认执行平台关键词搜索与本人点赞收藏同步，再生成本轮新增网页。不要只启动网页服务，也不要只跑搜索。无需再次询问已经授权的只读采集。若用户明确只要求重启网站，则只重启网站。

这是一份助手执行流程，当前没有一条能无人值守完成五个平台的命令。登录、浏览器连接、验证码和缺失的采集器需要如实处理。不得把流程文件当成已经完成同步的证据。

## 开始前

1. 读取当前技能与搜索项目配置。搜索沿用既有选题系统的启用关键词和规则；参见 [平台搜索](keyword-search.md)。
2. 保存本轮开始前库中所有平台和帖子编号。重建网页沿用这份基准，不能用更新后的库覆盖它。
3. 检查外置盘和资料库位置，不复制真实登录凭据。本人点赞收藏使用默认浏览器中本人的账号；批量搜索使用独立小号。搜索小号的收藏不能冒充本人的收藏。
4. 分别核实浏览器能读取标签、页面已登录、账号正确。仅能列出浏览器、侧栏已打开或存在历史缓存，都不能证明连接和采集成功。连接超时先修复连接，不对平台反复刷新。

## 低频读取

逐个平台、逐个列表串行操作，不同时打开五个平台采集。每次滚动至少间隔5秒，切换列表或关键词至少间隔20秒；平台提示需更长间隔时遵循提示。优先读已渲染的一批卡片，避免逐帖密集打开。每批最多20条候选，保存结果后再继续。

在连续两批已知内容后停止增量读取。加载没有进展时停止并记录部分结果；禁止无限重试。出现验证码、访问频繁、异常空白或登录失效，立即停止该平台，把验证交给用户；不切账号、切代理或加速重试绕过限制。其他不受影响的平台可继续。降低频率只能减少请求，不能保证不被风控。

## 五个平台的清单

| 平台 | 本人同步内容 | 执行依据 |
| --- | --- | --- |
| 小红书 | 点赞、收藏，含视频与图文 | 现有小红书列表采集器；先核实自己账号与页面 |
| 抖音 | 喜欢、收藏 | 现有抖音列表采集器；不能使用搜索小号代替本人 |
| X | 点赞、书签 | 正常页面读取真实帖子链接；视频与相关参考分别标类型 |
| Instagram | 点赞、已保存 | 点赞卡片链接转换需抽样核对；已保存使用现有流程 |
| TikTok | 点赞、收藏 | 先实测本人页面；目前没有专用列表采集器，不得声称已完成 |

搜索只执行当前确有可用入口的平台。当前已验证入口为小红书、B站与抖音；X、Instagram、TikTok 搜索没有完成接入时要明确标注，不用公开搜索替代平台内搜索并宣称完成。

## 最近一个月与相关性

本人同步默认最近一个月，以点赞或收藏行为的时间为准。Instagram 点赞页可核实互动日期筛选；其他页面没有行为日期时，按已确认的列表顺序截止位置处理。不能把发帖时间或本地抓取时间充当点赞时间。X 已授权只保留可确认在一个月内的帖子时，按保守可证明范围收录并说明可能不完整。范围无法确认的候选不进入已确认的本轮列表，可先留在私有待核验记录。

检查实际标题、文案和可见内容，收录 AI 创作、制作方法、开发教程、Vibe Coding、工具和网站案例等相关参考；无关日常、剧情、带货等排除，证据不足留待审核。不声称看过未观看的视频。随机项目挑战必须有随机选项目的开头及随后制作过程，不能只凭使用 Cursor 等工具就归入这一类。

## 入库与本轮网页

- 取得真实可打开链接就算完成链接采集。默认标题加链接，不下载媒体。
- 同一平台帖子编号去重，并保留搜索、点赞、收藏的多种来源。搜索必须保存当时关键词；缺失显示“未记录”。
- 保存平台、选题月份、真实抓取时间、作者、文案以及可确认的互动量和发布时间。未获取数据标未知。
- 完整库保留旧记录；本轮网页只显示本轮基准之外的新帖子。旧帖新增一个来源标签仍不算新帖子，不重复展示。
- 本轮新增搜索与点赞收藏放在同一个网页，支持月份、平台、来源、关键词筛选及原帖浮窗浏览。
- 仅有社媒参考链接才算参考；文字想法归灵感，允许关联零个或多个参考。合作文档和排期不冒充社媒帖子。
- 默认隐藏 X 点赞少于100、小红书点赞少于1000的内容；未知数量不当作0，隐藏项仍保留在完整库中。
- 下载本轮媒体或清理上轮媒体之前，必须先说明具体处理范围并获得用户确认。只读启动不触发媒体轮换。

## 结果核验

为每个平台和每个列表记录：未读取、读取部分、已读到截止点、需要登录或验证、连接失败。未读不能写“新增0条”；没有看到截止点不能标完成。记录读取候选数、已知重复数、排除数、待核验数和实际新增数。入库后核对本轮网页没有旧编号，关键词与来源标签正确，再打开网页。

公开仓库仅保存代码和通用流程；本人收藏、帖子链接、截图、浏览器账号目录和采集报告只留私有位置。启动结束后汇报实际新增数量、未完成平台及原因，不把旧缓存或历史同步数计入本轮成功数。
