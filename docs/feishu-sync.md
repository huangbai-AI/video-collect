# 候选框同步飞书

列表前方使用多选框，表头可全选当前筛选结果（包括尚未展开的条目）。勾选后底部出现操作栏，点击“一键同步到飞书”即可同步全部选中项，不必逐条点击。切换筛选保留选择，取消选择可清空；本月已同步项不可重复勾选。

需要调整时，点击“调整分类与描述”打开候选框。离线播放页和原帖控制条的“同步”按钮仍可加入候选。候选在本机浏览器保留，今日页面和完整库共用。

打开“同步候选”后可以调整每条的分类和内容描述、移除不想同步的条目。点击“启动同步”才开始写入；当前任务进行时防止重复启动。一次点击支持超过50条，后台分批逐组写入并读回验证，成功后从选择和候选移除，失败条目保留。

## 开启本机服务

先安装并登录官方 `lark-cli`。服务使用已有本机登录，网页不接触账号凭据。

在**资料目录之外的私有文件**配置月份目标：

```json
{"targets":{"2026-10":"https://your.feishu.cn/wiki/your-month-document"}}
```

```sh
python3 scripts/library_server.py --root /your/library --config /your/private/sync-config.json --port 8799
```

如果网页在上级目录路径下访问，可用 `--serve-root /your/library-parent` 保持旧网址。服务仅监听本机，拒绝其他来源的写入请求。普通静态网页服务无法执行飞书同步。

目标标题必须包含当月 `YYYY-MM`，缺少当月配置时停止，不自动写到上月文档。分类沿用：AIGC 教程、AI Coding、AI办公（泛 AI 效率 工具）、AI 设计、AI内容、其他灵感；目标需要对应标题及表格。

## 表格与截图

每条参考独立一行，内容放类型描述，参考放小尺寸显示的原始清晰截图，备注放带标题的原帖链接。按分类在现有表格之后追加同格式的参考表，保留原有选题和资源。

有多个参考但属于同一话题时，仍需由助手确认主题后合并，候选框不会擅自将不同选题并成一行。

截图可以预先放到 `<资料库>/feishu-sync/screenshots/<帖子id中的标点改成下划线>.png`，例如 `instagram_demo.png`。已有本地封面也可以使用。无本地截图时会标记“截图待补”，不会用虚构图片；本版不会自动控制已登录的平台批量截图或下载视频。

记录保存到私有资料库的 `feishu-sync/`。以月份和原帖身份去重，并在每次写入前检查飞书中已存在链接。重复点击不重复写入；超时或失败后必须核对记录再重试。网页关闭后，后台已经启动的任务仍会继续，服务退出则停止。私有同步记录和配置不要提交 GitHub。
